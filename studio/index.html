Première connexion

Le Studio a besoin d'une clé personnelle GitHub pour publier. Elle reste uniquement sur cet appareil.

  1. Ouvrez cette page GitHub (connecté à lacentrale-info).
  2. Token name : Studio tablette · Expiration : No expiration (ou 1 an).
  3. Repository access : Only select repositories → lacentrale-info.github.io.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. En bas : Generate token, puis copiez la clé (elle commence par github_pat_).
Modifier le titre ou la source
😏 Créer une image satirique (photo + bulle)

1. Choisissez une photo : la vôtre, ou une photo libre de droits sur Wikimedia Commons (les photos de presse sont protégées par le droit d'auteur).
2. Écrivez la bulle. 3. Touchez la bouche de la personne : la pointe de la bulle y va. Glissez la bulle pour la déplacer.
Le bandeau « SATIRE · La Centrale » est toujours ajouté : personne ne peut prendre la bulle pour une vraie citation.
