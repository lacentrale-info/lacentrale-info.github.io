Première connexion

Le Studio a besoin d'une clé personnelle GitHub pour publier. Elle reste uniquement sur cet appareil.

  1. Ouvrez cette page GitHub (connecté à lacentrale-info).
  2. Token name : Studio tablette · Expiration : No expiration (ou 1 an).
  3. Repository access : Only select repositories → lacentrale-info.github.io.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. En bas : Generate token, puis copiez la clé (elle commence par github_pat_).
